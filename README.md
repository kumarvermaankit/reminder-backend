# Personal Reminder Assistant

A NestJS-based API for managing personal reminders.

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Project Structure

```
src/
  app.controller.ts     # Basic application controller
  app.controller.spec.ts # Controller tests
  app.module.ts         # Root application module
  app.service.ts        # Basic application service
  app.service.spec.ts   # Service tests
  main.ts               # Application entry point
```
